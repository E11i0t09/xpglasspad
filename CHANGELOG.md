# Changelog

## v1.1.0
- New: GNS 530 + GNS 430 shown together (landscape side by side, portrait stacked like in the panel)
- New: option "Real display pixels" for the GNS (native 320x234 / 240x128 look)
- New: key lighting / night look – key legends and bezel lettering glow with the aircraft's panel/instrument dimmer, the housing darkens; unlit without avionics power; manual slider in the menu
- New: MENU key on every unit (the menu no longer opens by accident); pinch / double-tap zoom blocked in Safari
- Clearer key press feedback: keys travel deeper, stay down while held and show a small light ring; knob PUSH sinks in
- Fine plastic grain on the bezels
- App ignores units the aircraft registers but never draws (e.g. a hidden GNS in add-ons)
- Plugin: lighting values added to the status API
- MCDU / CDU support (Laminar A330, 737, MD-82, ToLiss) is in development and not enabled in this release
